Guides on manually adding a podcast url for some popular podcast applications.

## Pocket Casts

_iOS, Android_

1. Tap Discover
2. Paste URL into the search
3. Tap Search
4. Tap the Plus button

## Apple Podcasts

_iOS_

1. Tap Library
2. Tap "..."
3. Tap Add a Show by URL
4. Paste URL
5. Tap Follow

## YouTube Music

_Android, iOS, Web_

1. Tap Library
2. Scroll the library categories for "Podcasts"
3. Tap Add podcast
4. Tap Add podcast by RSS feed
5. Paste URL
6. Tap Add

## AntennaPod

_Android_

1. Tap ☰
2. Tap Add Podcast
3. Tap Add Podcast by RSS address
4. Tap Add

## PodcastAddict

_Android_

1. Tap +
2. Tap the RSS button
3. Paste URL
4. Tap Add

## Overcast

_iOS_

1. Tap the Search button
2. Tap Add URL
3. Paste URL
4. Tap Done

## Podbean

_Android, iOS, God I hate this app_

1. Tap Search
2. Tap +Feed
3. Paste URL
4. Tap Done

## gPodder

_Linux, MacOS, Windows_

1. Subscriptions
2. Add Podcast by URL
3. Paste URL
4. Tap Add

## VLC

_Linux, MacOS, Windows_

1. View
2. Playlist
3. Podcasts
4. Click the Plus next to Podcasts
5. Paste URL
6. Click OK
